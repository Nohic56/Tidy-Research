# Listing draft

## Name

Tidy Research — Clean Links & Search

## Summary

Remove tracking fields from links and open explicit UniProt, PubMed and Maps
searches from Firefox, DuckDuckGo or Google.

## Description

Tidy Research combines local link cleanup with useful shortcuts for scientific
browsing.

**Cleaner links**

Recognised tracking fields such as `utm_source=chatgpt.com`, campaign fields
and common advertising click IDs are removed before ordinary page navigations.
The cleaner preserves other query parameters, empty values, encoding and URL
fragments. Recognised signed and authentication links are left unchanged.

Use the toolbar popup to copy a clean link or clean the current address without
reloading. You can see removed field names, reopen a recent original address,
turn automatic cleaning off, or pause cleanup on specific websites. Reopening
the original reloads the page.

**Research shortcuts you choose**

Use `u` followed by Space in the Firefox address bar for UniProt lookup, or
choose PubMed or Maps from the suggestions. Accession-shaped queries open a
UniProt entry; names and keywords use UniProt search.

A small optional strip on DuckDuckGo and supported Google results offers the
same research links. Selected text can be searched using the right-click menu.
Your default search engine and homepage remain as you configured them. No
ordinary searches are automatically rerouted.

**Clear privacy controls**

No telemetry, advertising, accounts or developer backend. URL cleanup and
identifier recognition run locally. Search terms are sent only to the research
website you explicitly choose. Website access is required for automatic cleanup
across sites. See the privacy notice for local storage and search details.

Requires desktop Firefox 142+. Not all tracking schemes can be recognised;
site exceptions are available. Independent of Mozilla, DuckDuckGo, Google,
UniProt and NCBI.
